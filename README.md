# security-agent

中国大学生信息安全大赛作品赛项目。

本项目目标是实现一个面向授权安全场景的自主安全智能体，支持任务规划、工具调用、结果分析、报告生成等能力。

## 第一周目标

打通 Planner -> ReconExpert -> Execution -> 前端展示 的最小闭环。

## 目录结构

- agents/：智能体节点
- backend/：后端接口
- frontend/：前端界面
- prompts/：提示词模板
- sandbox/：工具执行与沙箱
- tests/：测试用例
- docs/：接口文档和进展记录
